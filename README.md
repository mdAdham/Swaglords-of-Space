# 🚀 SwagSpace

> A chaotic space game where strategy meets absolute swag. 🌌

**SwagSpace** is a 2D space-themed board game built from scratch in **C++** using **SFML**.

The goal of the project is to create a fun, polished game while experimenting with game architecture, networking, graphics, shaders, audio, UI, and modern C++.

## 🎮 About the Game

SwagSpace takes place in a chaotic space environment where player survive from space objects.

The game is being developed completely from scratch without using a traditional game engine.

## ✨ Features

- 🚀 Space-themed gameplay
- 🎨 Custom graphics and UI
- 🔊 Dynamic music and sound effects
- ✨ GLSL shader effects
- 🧩 State-based game architecture
- ⚙️ Settings system
- 💥 Custom gameplay effects
- 🛠️ Built with modern C++
